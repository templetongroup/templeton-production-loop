# Frontend Implementation Quality

Apply this reference to websites, landing pages, dashboards, screenshot-to-code work, and visually important application surfaces. Existing design systems, brand guidance, accessibility, and approved art direction take precedence.

## Establish the visual read

State internally: surface and audience, tone, design-system or aesthetic family, density, and one justified signature element. Ground choices in the product's real subject, content, and users—not current AI template defaults.

## Build protocol

- Inspect the styling stack, tokens, components, package manifest, responsive conventions, and existing behavior before changing UI.
- Preserve product function. Use an official design-system package already present rather than counterfeiting one.
- Use plain, specific copy and consistent action vocabulary. Never invent testimonials, metrics, claims, or social proof.
- Implement relevant hover, focus, active, disabled, loading, empty, validation, and error states.
- Define tablet/mobile collapse behavior for every multi-column layout.
- Prefer semantic HTML, visible focus, sufficient contrast, reduced-motion support, one icon family, and a disciplined type/color/spacing system.
- Verify the rendered surface with build/lint/tests and a browser or screenshot comparison when feasible.

## Reject generic output

Avoid unrequested purple/blue glows, centered hero plus three equal cards, decorative glass everywhere, huge floating rounded cards, fake app screenshots, random accent colors, placeholder-as-label forms, decorative motion, and brandless default typography. For workflow-heavy tools, prioritize clarity, hierarchy, state coverage, and information density over marketing-page novelty.

## Redesign order

Preserve brand, message, required content, conversion goal, accessibility, and behavior. Diagnose typography, spacing, contrast, hierarchy, responsiveness, state coverage, credibility, and generic patterns. Fix structure before decoration, then verify both behavior and visual artifact.
